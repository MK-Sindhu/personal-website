Research · Computers & Graphics, 3DOR 2026 special section

SLOT-GNNA hierarchical graph neural network for finding the missing part in a CAD assembly

Median rank 5 of 234,299 parts · 35% better than the strongest baseline

Given an assembly with a part missing, SLOT-GNN retrieves the right part from a library of 234,299. It encodes each part's boundary representation as a graph and passes edge-conditioned messages over the assembly's mate constraints.

  • Graph neural networks
  • B-rep encoder
  • Message passing
  • Retrieval

Agentic payments · Early access

ndStill

Nine checks on every agent transfer, before any money moves

A non-custodial control plane for AI agent spending. Agents pay from a business's own bank accounts, and each one gets caps instead of a balance: per-transfer, daily and monthly limits. Transfers that are over a threshold or look unusual wait for a person to approve them, a kill switch freezes one agent or the whole organisation, and every step goes to an append-only audit log. Agents connect through a REST API or an MCP server.

  • Rust
  • PostgreSQL
  • MCP server
  • REST API
  • Next.js

Distributed systems · Monitoring

Uptime Watch

Website checks every 30 s from regional workers

Regional workers check websites every 30 seconds and deliver results over Redis Streams with acknowledge-after-write. Results are stored in ClickHouse, where materialized views compute hourly uptime, median and 95th-percentile latency, and incidents. These are served through OpenAPI REST APIs and a Next.js dashboard.
